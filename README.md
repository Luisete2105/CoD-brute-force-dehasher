# CoD brute force dehasher
 My attempt to port the brute force dehasher I made on GSC to Python so I dont need to keep bo4 open and hopefully it will be faster

# 2.0

## UI created for easier use
    
    - You can see in real time the hashing results for your desired string and copy them with the clipboard button.
    - Now it detects the game you want to work on, just select the folder path to your downloaded GSC dump.
    - It auto organizes the hashes and words found on your folder location.
    - If a previous game.csv exists, both dictionaries are combined.
